🚢 Fragile travellersBananas, grapes, strawberries, mangoes and avocados are among the fruits most easily damaged on the way: wrong temperature, mould and ethylene are the big three.
👃 Fruit can "talk"Ripening fruit gives off ethylene; spoiling fruit gives off other gases. Your eyes can't see either.
📈 Read the trendSteady = healthy. Steady rise = ripening. Sudden spike = something may be spoiling.
♻️ Act early, waste lessShip what's fine, dispatch what's ripe, isolate and recover what's spoiling, so less food ends up in landfill.

📡 Option 1: Receiver micro:bit (recommended · most reliable)
The micro:bit inside the plush stays wireless. It uses micro:bit radio to talk to a second micro:bit plugged into the computer, which acts as the receiver. No pairing, no buttons, works with V1 and V2: the plush works as soon as it has power. Use this option with CreateAI gestures, because the bluetooth and radio extensions can't be used together in MakeCode.
After that, the game connects automatically whenever the receiver is plugged in, including after unplugging and plugging it back in.
Advanced: Option 2, direct Bluetooth (not recommended for the exhibition)
🔵 Option 2: Direct Bluetooth (no receiver)

Setup order (two micro:bit V2)

  1. Flash code ② onto the micro:bit that stays plugged into the computer (RECEIVER). It shows ✔.
  2. Flash code ① (no AI) onto the PLUSH micro:bit and power it from the battery pack. It shows ♥.
  3. Close every MakeCode / CreateAI tab, open this game in Edge and click Connect receiver once. Both chips turn green.
  4. Press A / B / A+B on the plush and watch the Live test light up. Only then add AI (code ①-AI).

Option 1 code ②: RECEIVER (plugged into the computer)

// RECEIVER micro:bit, plugged into the computer by USB (Fruit Rescue receiver v2)
radio.setGroup(23)
radio.setTransmitPower(7)
serial.redirectToUSB()

radio.onReceivedString(function (s) {
    serial.writeLine(s)          // plush → computer
    if (s != "HB") led.toggle(2, 2)
})
serial.onDataReceived(serial.delimiters(Delimiters.NewLine), function () {
    let m = serial.readUntil(serial.delimiters(Delimiters.NewLine))
    if (m == "PING") {
        serial.writeLine("PONG")  // lets the game check this is the receiver
    } else {
        radio.sendString(m)       // computer → plush (faces)
    }
})
basic.showIcon(IconNames.Yes)
serial.writeLine("PONG")

Option 1 code ①: PLUSH, no AI (buttons + built-in shake)

// PLUSH micro:bit, basic version (no AI). Do NOT add the Bluetooth extension.
radio.setGroup(23)          // must match the receiver
radio.setTransmitPower(7)

function send(cmd: string) {
    radio.sendString(cmd)
}
input.onGesture(Gesture.Shake, function () { send("SCAN") })
input.onButtonPressed(Button.A, function () { send("GO") })      // Ship It
input.onButtonPressed(Button.B, function () { send("RUSH") })    // Priority Dispatch
input.onButtonPressed(Button.AB, function () { send("CHECK") })  // Isolate & Recover

radio.onReceivedString(function (m) {
    if (m == "HAPPY") basic.showIcon(IconNames.Happy)
    else if (m == "SAD") basic.showIcon(IconNames.Sad)
    else if (m == "WORRY") basic.showIcon(IconNames.Confused)
    else if (m == "SCAN") basic.showIcon(IconNames.Target)
})
basic.forever(function () {
    radio.sendString("HB")   // heartbeat every 5 s
    basic.pause(5000)
})
basic.showIcon(IconNames.Heart)

Option 1 code ①-AI: PLUSH with CreateAI gestures

Paste this into the MakeCode project that CreateAI opens ("Edit in MakeCode"). A new project won't contain your model. Your CreateAI actions must be named exactly Shake, Push, Lift, Flip, Still.

// PLUSH micro:bit with AI gestures (V2). Paste into the CreateAI MakeCode project.
radio.setGroup(23)
radio.setTransmitPower(7)

let lastSend = 0
function send(cmd: string) {
    if (input.runningTime() - lastSend < 600) return   // one movement = one command
    lastSend = input.runningTime()
    radio.sendString(cmd)
}

// AI gestures. A gesture fires when the model CHANGES to it,
// so return to "Still" between two gestures.
ml.onStart(ml.event.Shake, function () { send("SCAN") })
ml.onStart(ml.event.Push, function () { send("GO") })      // Ship It
ml.onStart(ml.event.Lift, function () { send("RUSH") })    // Priority Dispatch
ml.onStart(ml.event.Flip, function () { send("CHECK") })   // Isolate & Recover

// Buttons stay as a backup while testing
input.onButtonPressed(Button.A, function () { send("GO") })
input.onButtonPressed(Button.B, function () { send("RUSH") })
input.onButtonPressed(Button.AB, function () { send("CHECK") })

radio.onReceivedString(function (m) {
    if (m == "HAPPY") basic.showIcon(IconNames.Happy)
    else if (m == "SAD") basic.showIcon(IconNames.Sad)
    else if (m == "WORRY") basic.showIcon(IconNames.Confused)
    else if (m == "SCAN") basic.showIcon(IconNames.Target)
})
basic.forever(function () {
    radio.sendString("HB")
    basic.pause(5000)
})
basic.showIcon(IconNames.Heart)

Train the gestures in CreateAI (V2)

  1. Open createai.microbit.org in Edge. Create 5 actions named exactly Shake, Push, Lift, Flip, Still.
  2. Connect using the radio link: PLUSH collects data, RECEIVER is the bridge (CreateAI flashes its own programs, that's normal).
  3. Record with the micro:bit inside the plush, in its final position. 15–20 samples per action, several people. Record Still facing up, upside-down and lying on the table.
  4. Train, then test each gesture in CreateAI. Fix weak ones before going on.
  5. First click Edit in MakeCode and download the project unchanged: the plush LEDs should show a different icon for each gesture. This proves the model works on the micro:bit itself.
  6. Then, in the same project, switch to JavaScript, select all the code and replace it with code ①-AI. Your model is kept in a separate file of the project, so it stays. Download to the PLUSH.

After training in CreateAI, always re-flash code ② onto the RECEIVER, because CreateAI replaces its program. The Receiver chip turns red ("needs program ②") if you forget.

Option 2: direct Bluetooth setup

  1. In MakeCode click Extensions and add bluetooth (it removes radio, which is expected). Without this extension the micro:bit sends no Bluetooth signal at all.
  2. ⚙ → Project Settings → choose No Pairing Required: Anyone can connect via Bluetooth → Save, then download again to the micro:bit.
  3. Do not press A+B+Reset for pairing mode. That mode is only for the phone app, and your program isn't running then. If you enter it by mistake, press Reset on the back.
  4. Do not pair it in Windows Settings → Bluetooth & devices. If you already did, choose "Remove device".
  5. The computer needs Bluetooth 4.0 (BLE) or later. Very old Bluetooth USB dongles (2.x / 3.0) won't work.
// Bluetooth plush program (add the bluetooth extension first)
let connected = false
bluetooth.startUartService()
bluetooth.onBluetoothConnected(function () { connected = true; basic.showIcon(IconNames.Happy) })
bluetooth.onBluetoothDisconnected(function () { connected = false; basic.showIcon(IconNames.Asleep) })
function send(cmd: string) { if (connected) bluetooth.uartWriteLine(cmd) }
input.onGesture(Gesture.Shake, function () { send("SCAN") })
input.onButtonPressed(Button.A, function () { send("GO") })
input.onButtonPressed(Button.B, function () { send("RUSH") })
input.onButtonPressed(Button.AB, function () { send("CHECK") })
bluetooth.onUartDataReceived(serial.delimiters(Delimiters.NewLine), function () {
    let m = bluetooth.uartReadUntil(serial.delimiters(Delimiters.NewLine))
    if (m == "HAPPY") basic.showIcon(IconNames.Happy)
    else if (m == "SAD") basic.showIcon(IconNames.Sad)
    else if (m == "WORRY") basic.showIcon(IconNames.Confused)
    else if (m == "SCAN") basic.showIcon(IconNames.Target)
})
basic.forever(function () { if (connected) bluetooth.uartWriteLine("HB"); basic.pause(5000) })
basic.showString(control.deviceName())   // Scrolls the 5-letter Bluetooth name at start-up
basic.showIcon(IconNames.Asleep)

Can't find it? Type edge://bluetooth-internals in Edge (or chrome://bluetooth-internals in Chrome) → Devices → Start Scan. If BBC micro:bit [xxxxx] appears, the plush is broadcasting and the problem is on the web page side. If it doesn't, check the plush program or the computer's Bluetooth.
